
# TaskFlow

Лабораторна робота №2 з дисципліни «Кросплатформне програмування».

## Тема
Розроблення об'єктної моделі застосунку.

## Індивідуальне завдання
Варіант №2 — «Курс відеоуроків».

## Опис проєкту
TaskFlow — Java-застосунок для керування завданнями
з підготовки навчальних відеокурсів.

Основні сутності:
- User — користувач системи.
- Project — проєкт навчального відеокурсу.
- Task — завдання з підготовки відеоуроків.
- CompletionPolicy — інтерфейс перевірки завершення.

## Правило завершення
Для завершення завдання необхідно:
- записати щонайменше 3 відеоуроки;
- отримати погодження редактора.

Кількість зауважень не впливає на прийняття результату.

## Технології
- Java 25
- Apache Maven
- JUnit Jupiter 6.0.3
- Apache NetBeans IDE 31

## Стан розробки
Початкова структура проєкту створена.
Реалізація об'єктної моделі та тестування заплановані
на наступних етапах.
