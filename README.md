
# TaskFlow

Лабораторна робота №2
Дисципліна: Кросплатформне програмування

## Тема
Розроблення об'єктної моделі застосунку.

## Мета роботи
Створення об'єктної моделі застосунку TaskFlow
для керування завданнями та перевірки коректності
операцій над об'єктами.

## Індивідуальне завдання
Варіант №2 — «Курс відеоуроків».

## Опис застосунку
TaskFlow — навчальний Java-застосунок для керування
завданнями з підготовки відеокурсів.

Користувач створює проєкт відеокурсу, призначає
виконавця завдання та контролює його виконання.

Основні сутності:
- User — користувач системи.
- Project — проєкт відеокурсу.
- Task — завдання з підготовки відеоуроків.
- Status — стан виконання завдання.
- CompletionPolicy — інтерфейс перевірки завершення.
- VariantPolicy — реалізація правила варіанта №2.

## Стани завдання
NEW → ACTIVE → DONE

Перехід між станами здійснюється за допомогою
методів assign(), start() та complete().

## Правило завершення
Параметри:
- units — кількість записаних відеоуроків;
- defects — кількість зауважень;
- approved — погодження редактора.

Завдання можна завершити, якщо записано не менше
3 відеоуроків та отримано погодження редактора.

Кількість зауважень не впливає на результат.

Умова:
units >= 3 && approved
